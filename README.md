# Luxury Fitness Hub - Clean Replit/GitHub Version

This ZIP is cleaned for GitHub and new Replit account import.

## How to run in Replit
1. Create a new Replit project using **Node.js**.
2. Upload/extract these files, or push this folder to GitHub and import from GitHub.
3. Open Shell and run:

```bash
npm install
npm run dev
```

## Deploy permanently
Use Vercel or Netlify.
- Vercel: import GitHub repo, it will run build automatically.
- Build command: `npm run build`
- Output folder: `dist`
